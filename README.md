# Vũ Thu Chi
Ứng dụng quản lý thu chi cá nhân, mobile-first.

## Chạy
Mở `index.html` hoặc deploy thư mục này lên GitHub Pages.

## Tính năng V1
- Dashboard số dư / tổng thu / tổng chi
- Biểu đồ thu chi
- Giao dịch gần đây
- Thêm giao dịch Thu/Chi
- Danh mục: Lương, Forex, Trading, Phụ thu, Sinh hoạt, Mua sắm, Quà cáp, Đi lại
- Responsive mobile
